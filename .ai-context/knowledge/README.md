# Project knowledge

`.ai-context/` is the shared, compact context for agents working on this repository.

- Generated facts are derived from the current source tree and include evidence paths.
- Curated guidance is human-authored or explicitly approved. It must not be silently replaced by inferred summaries.
- Statements marked `inferred` describe a safe engineering relationship that was not explicitly documented as a business rule.
- Source code, Compose files, runtime data, and explicit operator rules remain authoritative over this context.
- Secret values are never copied here. Only the existence, variable name, and configuration role may be recorded.
